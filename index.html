How to use

1Enter a reference stringType page numbers separated by spaces, press Random, or pick a preset.
2Set the framesChoose how many memory frames (1 to 8) are available to the OS.
3Pick an algorithmSwitch between FIFO, LRU and Optimal. The panel below explains each one.
4Play and analyseWatch each hit, fault and eviction, then compare all algorithms and the frame-sweep chart.

Shortcuts: Space play or pause   → next step   ← previous step

Key features

🔁 FIFOEvicts the page that has been in memory the longest. Simple, but can suffer Belady's anomaly.
🕒 LRUEvicts the least recently used page, exploiting temporal locality. A stack algorithm.
🔮 OptimalEvicts the page whose next use is farthest away. The theoretical lower bound on faults.
🎬 Step-by-step animationPlay, pause, step forward or back, change speed, or jump to the end.
📊 Side-by-side comparisonAll three algorithms run on the same input with the winner highlighted.
⚠️ Belady's anomaly demoOne-click preset shows FIFO faulting more with extra frames.
📉 Frame-sweep analysisA line chart of faults for 1 to 8 frames, so you see how memory size changes each algorithm.
🧾 Eviction trackingA dedicated row shows exactly which page was evicted at every fault.
🧠 Built-in explanationsEach algorithm shows its rule, complexity, strengths and weakness, ideal for revision.
⌨️ Keyboard controlSpace, left and right arrows drive the simulation hands-free during a presentation.
⚡ Instant, no installPure client-side code. Every input change recomputes all results immediately.
